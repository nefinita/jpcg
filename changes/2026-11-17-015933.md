# 修复本机 npm 12+ 下 make setup 的 EALLOWREMOTE 失败

## 现象与原因

- `make`（首步 `make setup` → `npm ci`）在本机（Node 26 / npm 12.2.2）报错：
  `EALLOWREMOTE: Fetching packages of type "remote" have been disabled`，
  拒绝抓取 `yallist@https://registry.npmmirror.com/...` 等锁文件内 URL。
- npm 12 起 `allow-remote` 默认从 `all` 收紧为 `none`：凡 tarball 主机名与
  当前配置 registry（本机为 registry.npmjs.org）不同的依赖一律拒绝。
- 前端锁文件 `examples/jpcg_app/package-lock.json` 有 114 个 resolved 指向
  `registry.npmmirror.com`（历史生成与 dependabot 来源），与默认 registry 主机不同，
  故 npm ≥ 12 的用户本地必现；CI 用 node 22 / npm 10（无此限制）不受影响。

## 改动

- 新增 `examples/jpcg_app/.npmrc`：`allow-remote=all`。
  - 不改锁文件（延续 2026-10-30 决策，dependabot 会继续以 npmmirror 再生成）；
  - 按 npm 官方建议「按项目显式放行」，行为对齐 npm ≤ 11（从锁文件记录的主机拉取，
    integrity 逐包校验不变）；
  - 对 make / 裸 `npm ci` / `npm install`（tauri dev）等所有调用方式一致生效；
  - CI 的 npm 10 不认识该键，仅告警不失败。

## 验证

- `make setup`：npm ci 成功（added 162 packages）。
- 完整 `make`（默认目标 build-static：setup → frontend → updater → cargo build）通过。
