# fix: beta 通道应用更新下载 URL 缺分隔符（404）

日期：2026-09-08

## 背景
beta 通道点"下载更新"报 `下载失败: 下载文件失败，HTTP 状态码: 404 Not Found`。

根因：`fetch_app_update_info` 里 beta 分支拼下载 URL 用
`format!("{}{}", base_url.trim_end_matches('/'), target_binary.path)`，
而 beta 清单在通道根、`path`（如 `jpcg-app-macos-aarch64`）无前导 `/`，
base_url trim 后也无结尾 `/` → 拼成 `.../updates/JPCG_betajpcg-app-...`，
nginx `/updates → /files` 重写后查无此文件 → 404。
stable 分支（`{}/{}/{}` 带 `dir_name`）不受影响，故此前仅 beta 通道必现。

## 变更
- `crates/jpcg_update/src/lib.rs`：beta 分支 URL 改为 `format!("{}/{}", …)`，补上分隔符

## 验证
- 修复后 URL = `https://nefinita-ai.com/updates/JPCG_beta/jpcg-app-macos-aarch64`，
  与服务器实际文件一致（200）
- 服务器 beta.2 资产/清单此前已逐项 curl 验证 200；唯一 404 即该拼接错误
