# 测量窗口改为「动作归属 + 显式边界」（修复同刻前后技能 / start=0 / 零窗口）

## 问题
上一版用「结束标记时刻 - 1e-3」整体平移上界，带来：
- 上一招 `cast_time=2s`、命中与下一招起点同为 2s 时，结束标记会把上一招的合法命中也剔除；
- `start=0` 时 `max(0)` 让减 epsilon 失效，结束标记 + 瞬发仍会进入总伤；
- 显式开始/结束邻接（零窗口）没有被统一处理。

## 修复（按动作归属，不再平移时间上界）
- `TimelineEvent` 新增 `owner_step`（产生事件的 step；DOT 跳 = 施加该 DOT 的 step），
  `DotInstance` 新增 `step_index`，动作循环里按 `steps.len()` 标记。
- 测量窗口 = **动作 step 区间**：`window_first = 开始标记 step + 1`、`window_last = 结束标记 step - 1`；
  显式开始/结束邻接 → 空窗口（总伤/击杀率均为 0）。
- 窗口内判定：
  - 施放/引导：按 `owner_step` 归属（同刻前后两招可区分），并受模拟窗口约束；
  - DOT 跳：按时间窗口（`kill_start <= t <= kill_end`），窗口外 DOT 尾跳不计入。
- 击杀率曲线按窗口 step 输出；`TimelineResult` 新增 `visible_events`（窗口内事件），
  DTO 伤害日志只返回它——日志/总伤/击杀率同一口径。
