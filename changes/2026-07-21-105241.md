# 属性配置改为应用内读取与保存

## 改动内容

- 移除属性编辑器的外部 TOML 打开、下载导出和剪贴板复制操作，只保留保存入口。
- 进入属性配置页时自动读取当前心法，并允许在项目已有心法配置之间切换。
- 新增 Tauri 读取与保存命令，将配置写回计算引擎实际使用的 `data/shuxing` 目录。
- 保存前由 Rust 端校验文件名、`[xinfa]` 信息和 `[[skill]]` 条目，只允许覆盖已有配置。
- 读取现有配置时兼容并保留 `[version]` 与 `huixin_up` 数据，保存内容使用计算引擎可直接读取的格式。
- 移除属性编辑器的浏览器本地草稿，未保存状态由当前文件内容实时判断。

## 改动原因

管理要求配置只能在应用内保存，不允许通过文件选择器打开或导出 TOML；配置读写还必须与 JPCG 计算引擎使用的目录保持一致。

## 重要决策

- 本阶段不创建新配置文件，后端仅接受心法列表中已有文件的安全文件名。
- 编辑字段仍以 `_template.toml` 和 `datamake.md` 为准，但落盘时使用现有运行时要求的 `[xinfa]` 结构。
- 保留只读 TOML 预览用于核对生成内容，不提供复制或下载动作。
