# 保留技能编辑保存时的心法基础 GCD

修改技能编辑器中的名称等无关字段时，加载请求和保存请求都包含 `gcd_base`，但后端重建心法配置时将它留在构造器默认值 0，造成原来的非默认公共调息被写丢。没有其他覆盖时，时序随后回退至 1.5 秒。

保存入口现在保留请求中的基础 GCD。未改变计算公式、默认值、DTO 或正式数据；也不会自动修复已被旧版本写成 0 的文件。

子进程回归使用隔离临时数据根，覆盖从旧布局加载、只改名称、保存到新布局及重新读取。最初 1.0 秒夹具落盘为 0.0，修复后为 1.0；默认 0.0 仍使用 1.5 秒。云端 core 测试（含金标准）和格式检查通过；未做原生桌面实机验收。
