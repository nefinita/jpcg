# 奇穴第 2 层：激活门控与奇穴主动技能

## 做什么

- `QixueDef` 增加 `grants_skills`（该奇穴解锁的技能列表），`QixueDefDTO` 同步；`validate()` 允许「只解锁、不修饰」的奇穴，`validate_against_skills()` 校验解锁技能存在。
- `SkillCombatDef` 增加 `jihuoqixue` 覆盖字段，套 overlay 时写入 `Skilltype.jihuoqixue`。
- 时序引擎 `TimelineInput` 增加 `active_qixue`：`resolve_skill` 会跳过 `jihuoqixue` 非空且未激活的技能。
- `calculate_timeline` 从请求的 `qixue` 取出激活奇穴，同时把 id 与名称放进 `active_qixue`（技能里两种写法都能命中），并对每个技能套已激活奇穴的 modifiers。
- `resolve_skill` 对「同 key 的重复条目」不再一律判歧义：先按名称过滤，名称唯一命中且 key 相同的重复条目取第一条（奇穴技能常见 `(lv1)` / `>70%血量` 两个变体同名不同 key，仍按名称区分）。
