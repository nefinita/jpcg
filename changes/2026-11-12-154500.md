# 击杀概率曲线横轴关联到技能名

## 问题
`kill_prob_curve` 只有 `(第几招, 概率)`，而 `TimelineStepDTO` 不带技能名，
前端曲线横轴只能显示「第 N 招」，无法和技能对应。

## 修复
- `TimelineStepDTO` / 内部 `TimelineStep` 新增 `skill_name`：
  - 施放动作 = 解析后的技能名；
  - 计算开始 / 计算结束 = 对应说明文字；
  - 器形切换 = 「切换器形」。
- `timeline_host` 转换补 `skill_name`。
- 前端曲线横轴改为 `序号.技能名`（如 `3.商`），并旋转 35° 防重叠；
  技能名缺失时回退 `第N招`。

## 验证
- `cargo test --workspace` / `cargo fmt --check` 全绿。
- 前端 `tsc` + 157 项 vitest + `npm run build` 通过。
