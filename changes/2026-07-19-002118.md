# Rust 1.97.1 桌面应用构建入口

## 改动内容

- 新增 `script/build_and_run.sh`，统一执行 JPCG Tauri 桌面应用的停止、release 构建、打包与启动。
- 构建脚本强制校验 Rust 1.97.1，并支持运行、调试、日志、遥测、启动验证和安装包模式。
- 新增 `.codex/environments/environment.toml`，将 Codex 的 Run 动作连接到统一构建脚本。

## 改动原因

为后续在现有 JPCG 桌面应用基础上继续开发提供稳定、可重复的本机构建与运行入口，避免不同 Rust 工具链导致产物不一致。

## 重要决策

- 不新增或修改应用功能，本次只建立桌面应用构建链路。
- 使用 keg-only 的 `rustup` 工具链，避免替换系统已链接的 Homebrew Rust。
- 日常运行只生成 macOS `.app`；`--package` 模式同时生成 `.app` 与 `.dmg`，避免每次运行都重复制作安装盘。
- 本地产物跳过发布签名和公证，仅用于当前机器上的开发与验证。
