# 修复：只放「计算开始」时，击杀测量窗口默认到 300 秒

## 问题
排轴器里只放了「计算开始」、没放「计算结束」时，击杀概率的测量窗口默认是 300 秒模拟窗口。
连招结束后 DOT 会继续跳完，击杀率被高估；用户期望窗口「紧跟最后一个技能」结束。

## 修复
- `crates/jpcg_combo/src/timeline.rs`：`end_flag_time` 缺失、但存在「计算开始」标记时，
  默认取**最后一个动作的结束时刻**（`now`，即最后一次施放命中时刻），而不是固定窗口。
- 没有放任何 flag 时保持原默认（模拟窗口），不改变未使用 flag 的确定性击杀率口径。

## 验证
- 新增 `kill_end_defaults_to_last_action_not_window`：只放开始标记 + 3 次瞬发，断言 `kill_end` = 最后一次命中 3.0s，而不是 30s 窗口。
- `cargo test --workspace` / `cargo fmt --check` 全绿。

## 说明
- 总伤 / 区间 DPS 仍按模拟窗口统计（含 DOT 尾跳）；本次只改击杀率测量窗口。
