# 计算后端枚举 + 批量精确 MC + 调优停止按钮

## 新增
- `crates/jpcg_compute`：`list_backends()`（CPU：AVX-512/AVX2/NEON + 型号 + 线程数；
  wgpu：枚举全部适配器）与 `run_batch()`（CPU 或 `wgpu:<n>` 批量跑 50k MC）。
  同一 seed 下 CPU 与 wgpu 的击杀计数逐候选相同（Mac Metal 上已对拍）。
- `jpcg_combo::kill_mc`：f32 + 计数器哈希的 MC 内核（标量参考 + x86 AVX-512 16 路），
  时间轴引擎的击杀率 MC 改用它（调优与计算器同口径）。
- `jpcg_gear::optimize_joint`：击杀率目标改为「按选中后端的批量精确 50k MC」
  （32k 候选/批，跨批跟踪 best/pareto，支持取消），替换原来的正态近似搜索。
- Tauri：`list_compute_backends`、`cancel_gear_optimize`；`optimize_gear` 改走
  `optimize_joint`，并把运行中的 `OptimizeProgress` 存进 `OptimizeState` 供停止。
- 前端调优设置：新增「平台」下拉（自动/CPU/各 wgpu 适配器）与运行中的「停止」按钮；
  请求携带 `compute` 字段。

## 验证
- `kill_mc` 单测（ws：标量与 AVX-512 完全相等）；`jpcg_compute` 测试（Mac：CPU 与 Metal 相等）；
  `jpcg_gear` 测试全绿；前端 157 项 vitest + tsc + build 通过。
