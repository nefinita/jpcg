# fix: 更新检查/执行无限等待（无超时 + 嵌套 runtime）

日期：2026-09-08

## 背景
beta.1 构建中点击"检查更新"卡在"正在检查更新..."不返回（Beta 开关开/关都卡）。
服务器侧所有被请求 URL 均 200，定位为客户端代码层。

## 变更
- `crates/jpcg_update/src/download.rs`：新增 `http_client()`（统一 60s 超时），
  全部 5 处 `reqwest::Client::new()` 改用之
- `crates/jpcg_update/src/modules.rs`：模块清单请求同样走带超时客户端
- `examples/jpcg_app/src-tauri/src/commands/update.rs`：`check_update` /
  `perform_update` / `perform_app_update` / `perform_modules_update` 同步实现
  移入 `tauri::async_runtime::spawn_blocking`，避免在 async 命令线程内嵌套
  新建 tokio runtime（`block_on`），消除潜在挂起

## 验证
- `cargo check -p jpcg_update` / `-p jpcg_app` 通过
- 效果：任何网络卡点 60s 内转为明确报错；命令不再无界等待
