# 莫问第一重奇穴「洞天」伤害降低 5%

## 背景
2026-11-12 技改：第一重奇穴【洞天】伤害降低 5%。

## 改动
- `data/combat/mowen.toml` 洞天替换技能（`qixue.dongtian.replacement`）：
  `base_damage1` / `base_damage2` 由 **4851 → 4608**（4851 × 0.95 = 4608.45，取整 4608）。
  3 跳合计 14553 → **13824**，正好降低 5%。
- 洞天的 `accelerate_dot` 钩子（让商/角下一跳提前生效）不受影响。
- 同步注释：`data/combat/mowen.toml` 第 784 行、`crates/jpcg_combo/tests/qixue_hooks.rs` 注释。
- `data/combat/mowen.toml` `[meta].version` 2026-11-05 → 2026-11-12。

## 验证
- 新增回归 `dongtian_damage_is_nerfed_to_4608`：洞天 3 跳，单跳经引擎伤害链路为 4149
  （base 4608 经 PVP 0.9 等取整；削弱前 base 4851 约 4368，4149/4368 ≈ 0.95）。
- `cargo test --workspace` / `cargo fmt --check` 全绿；前端 test/build 同步验证。

## 说明
- 未改 3 点曲风消耗（当前引擎未建模该消耗）。
- `dot_up` 是「每跳等比递增」系数，不适合做整体 5% 削弱，因此直接缩基础伤害。
