# 击杀概率曲线只覆盖「计算开始 → 计算结束」

## 问题
`kill_prob_curve` 对整条 `steps`（所有动作）逐招建点，飞行窗口（计算开始前、计算结束后）的步骤
也出现在曲线上，看起来像击杀率计算覆盖了整条连招。

## 修复
- `crates/jpcg_combo/src/timeline.rs`：记录 start/end flag 所在的 step 下标，
  曲线只保留 `[start_flag_step, end_flag_step]` 之间的点；无对应 flag 时回退到整条序列。
- 曲线点仍带原始 step 序号（1-based），前端「序号.技能名」映射不受影响。

## 验证
- 新增 `kill_curve_only_covers_flag_window`：cast/开始/cast/结束/cast 时曲线首尾为 2..4。
- `cargo test --workspace` / `cargo fmt --check` 全绿；前端 tsc + 157 项 vitest + build 通过。
