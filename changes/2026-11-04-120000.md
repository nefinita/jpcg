# 2026-11-04 12:00:00

## 新增：skill-shots 截图 OCR 工具

### 做什么

新增 `server_tools/skill-shots`：把人工截的游戏截图（技能 tooltip、秘籍选择页、
奇穴页、属性面板）批量 OCR 成结构化 JSON，用来校对技能基础伤害与倍率。

### 为什么

现代客户端（含无界）把玩家伤害公式移到引擎侧，`scripts/skill/*.lua` 只保留
「调用哪个伤害通道」，无法再从 Lua 抽公式；而 tooltip 会同时给出
`基础区间 + 攻击力贡献`，配合属性面板的「最终XX攻击」即可反推倍率
（当前版本内外功统一，基准 192）。

### 实现要点

- 目录约定驱动：`<职业>/技能/<技能名>/` + `秘籍/` 子目录、`<职业>/奇穴/<1..9>/`，
  换图即可重跑，不改代码。
- OCR 用系统 `tesseract`（chi_sim+eng），多 psm（4、11）结果拼接提高字段命中率。
- tooltip 解析：基础区间、攻击力贡献、五行属性、释放/加速修正、调息、距离、
  内力消耗、数值型修饰；抽不到的字段留 `None` 并写入 `warnings`，不猜。
- 整页截图（秘籍/奇穴）先用 `sips` 按网格切卡，再逐卡 OCR：整页 OCR 在游戏字体
  下几乎不可用，切卡后效果文案正确率大幅提高。
- 输出 `out/<职业>.json` + `out/summary.json`，含 `ratio_residual` 供校验。

### 验证

- `cargo test -p skill-shots`：解析与归一化单测 5 项通过。
- 用无界「宫」tooltip + 属性面板截图实测：`22018 / 8438 × 192 = 501.002`，
  残差 0.002，与仓库 `data/raw-src` 中宫（14474）的 `2.609375 = 501/192` 一致；
  秘籍整页 8 张卡中 6 张效果文案与数值完全正确，2 张为 OCR 误读（保留原文）。

### 追加（同日）：奇穴 tooltip 解析

奇穴页是「4 重 × 4 个奇穴」的固定网格，点开单个奇穴才有 tooltip。约定
`<职业>/奇穴/<第X重>/<奇穴名>.png`，每奇穴一张面板截图：

- 解析出 `name`（文件名）、`kind`（主动招式/被动招式）、`text`（效果正文，逐行拼接）、
  `targets`（“变徵”“商”“角”这类被引用的技能）、`numbers`（伤害/秒数/层数）。
- 截到的是整页列表时自动退化成切卡模式，只当清单校验用。
- 小图先由 `sips -Z 1600` 放大再 OCR：实测 730px 宽的 tooltip 直接识别会把「变徵」
  认成「变征」、漏掉百分号，放大后文案基本可读。

### 追加：奇穴整窗截图 + 绝招解析

- 奇穴截图可以直接截整个武学窗口：`recognize_auto` 把窗口切成 4 块候选区域
  （右中 / 左中 / 右偏下 / 全图），逐块放大 OCR 后按「汉字数 + 关键词命中 - 拉丁噪声」
  打分取最优，避免整窗 OCR 的噪声压过面板文案。
- 解析从「被动招式 / 主动招式 / 绝招」标记处截正文（OCR 常把「招式」认成「招却」），
  到「装备 / 无界 / beta」结束；多 psm 产生的重复句子按 2-gram 相似度去重。
- 「绝招」类奇穴（如莫问第六重·不愧君）额外按技能 tooltip 解析：
  `850-875点(+92291)`、调息 20 秒、距离 20 尺、阴性内功，输出到 `active` 字段。
- 目录支持 `第一重`~`第六重` 与 `混选奇穴`（之前的 4 重是只看到部分截图时的误判）。
- 单测 7 项通过（新增绝招解析用例）。

### 追加：名词白名单纠错 + 混选奇穴

- OCR 纠错分两层：引号内技能名按 `data/shuxing/*.toml` 的 `skill_name` 做编辑距离
  1 匹配（`“变惩”→“变徵”`），以及实测高频错词表（`曲凡→曲风`、`招却→招式`……）。
  不做任意两字滑窗替换（会把「根据→根骨」这类正文改坏），所有替换写进
  `corrections` 数组供复核。
- 奇穴槽位：`第一重`~`第六重` 输出 `slot_index: 1..6`；`混选奇穴` 输出
  `pool: {size: 9, pick: 3, slot_from: 7, slot_to: 9}`，对应 #92 的
  `QixueDef.slot = 7~9`，具体分配由玩家运行时决定。
- 新增 `--names <dir>` 参数（默认 `data/shuxing`），白名单词数会打印在 stderr。
- 混选奇穴的 7~9 号槽位由游戏按混池顺序**自动排序**，工具不指定槽位，只记录池子
  元数据（9 选 3）；运行时按生效顺序取用即可。

### 追加：奇穴主动技能直接产出 #92 技能条目

- `奇穴` 槽位输出新增 `skills[]`：`kind == 绝招` 的奇穴会生成一条
  `{ name, jihuoqixue, active, ratio, ratio_int, ratio_residual }`，其中
  `jihuoqixue` = 该奇穴名，`active` 是技能 tooltip 解析结果，`ratio` 由
  `攻击力贡献 / 面板攻击 × 192` 反推（不愧君实测 92291/8438×192 = 2100.01 → 2100）。
- 与 #92 的 `jihuoqixue` 门控对应：激活奇穴后才进时间轴，未激活整条跳过。
