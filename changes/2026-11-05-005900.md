# 小图先放大再 OCR + 莫问技能数据采集

## 做什么

- `server_tools/skill-shots`：`ocr::recognize_auto` 对宽度小于 900px 的截图先 `sips -Z` 放大到 900px 再识别。
  之前小图（niri 选区截图，宽 380~450px）直接送 tesseract，标题和数字经常糊掉；
  放大后同一批截图的识别率明显提升（例如「距离 / 释放 / 调息」头部行能被读出）。
- 采集莫问（长歌）全量技能数据：24 个技能（音/剑两形态 + 曲/气/影）、35 个奇穴（第一~第六重 + 混选池）、8 页秘籍。
  截图存 `data/skill-shots/莫问/`（已在 `.gitignore` 忽略），最终整理成 `data/skill-shots/out/mowen-final.json`。

## 为什么

- 游戏内 tooltip 是唯一能直接读到「基础伤害 / 攻击加成 / 释放 / 调息」的地方；
  客户端 Lua 里的伤害公式已迁移到引擎侧（见 #92 讨论），截图 + OCR 是当前成本最低的采集方式。
- `宫` 与 `阳春白雪曲` 两张截图录制时角色带「全属性 +29」buff，攻击加成偏高；
  按其它技能前后差值算出系数 0.99694 校正（`宫 +2723 → +2715`，`阳春白雪曲 +1145/+1308/+57780 → +1141/+1304/+57603`），后续可替换为无 buff 截图。

## 数据口径

- 基准攻击力：最终阴性内功攻击 **8438**（属性面板截图），`倍率 = 攻击加成 / 8438`。
- 变宫/变徵 = 宫/徵 在「高山流水」曲下的变体，复用其秘籍；剑系列（剑·宫…）不吃秘籍。
- 奇穴 混选池 = 9 选 3（槽位 7~9），由游戏按池顺序自动排列。
