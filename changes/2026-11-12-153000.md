# 总伤 / DPS / 模拟伤害记录改为「测量窗口内」的伤害

## 问题
之前 `total_damage` / `window_dps` / 模拟伤害记录都按 300 秒模拟窗口统计，
连招结束后的 DOT 会继续跳完；用户期望「计算开始 → 最后一个技能」窗口内的伤害。

## 修复
- `crates/jpcg_combo/src/timeline.rs`：
  - 有效测量窗口 `kill_start → kill_end`：开始缺省 0；结束缺省 = 最后一个动作结束
    （若最后一次施放带 DOT，则取该 DOT 的最后一跳到尾，因为那是最后一次施放自己的伤害）。
  - 总伤 / DPS 只统计窗口内伤害：`DPS = 窗口总伤 / (末次伤害时刻 - 窗口起点)`。
  - 返回有效窗口：`kill_start` / `kill_end` 始终为 `Some(..)`（缺省已折算）。
- 前端：
  - `TimelineDamageLog` 只展示窗口内事件，累计伤害按窗口内重新累加（末行 = 窗口总伤）。
  - `ComboPage` 结果行新增「测量窗口 X–Ys」。
  - `CockpitCombo` 显示窗口起止。

## 验证
- `cargo test --workspace` / `cargo fmt --check` 全绿（更新了 3 个旧口径测试）。
- 前端 `tsc` + 157 项 vitest + `npm run build` 通过。
- 用户保存排轴：窗口 `7.88–14.44s`，窗口总伤 74301（原 300s 口径 84270）。
