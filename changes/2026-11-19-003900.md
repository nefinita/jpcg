# PR #115：修复 PigeonMuyz 的未解决审查问题

## 修改与原因

- 调优在首次异步加载前取得互斥锁，请求构建纳入统一错误处理与 finally；空请求、加载失败及执行结束均可靠解锁，连续点击不会启动多个任务。
- 停止按钮移到 inert 编辑区及点击拦截器之外；保持其余输入锁定。准备请求时也可以请求停止，准备完成后不会再启动后端搜索；运行中的停止仍调用取消入口，等待后端返回部分结果后解锁。
- 调优设置接入「导出穷举请求」，传递当前目标、平台、四件套及加速约束；下载过程异常会显示错误提示。
- 时间轴未显式结束时统一在 DOT 排程后推导结束时间。只有开始标记时不再截断最后技能自己的 DOT 尾跳，显式结束标记仍截断尾跳。
- 伤害日志直接展示 Rust 返回的可见事件与累计值，不再按旧时间窗口二次过滤，保留同刻边界前一招的读条命中。
- 恢复秘籍数值回归的 #[test] 标记，去掉重复标记；补基础技能和共享变体的实际增伤、读条修正断言。
- 更正洞天测试注释及原变更说明：4149 来自零化劲等级下 102/1024 基础减伤；降低比例为约 5%，断言不变。

## 已有修复核对

当前 HEAD 已具备完整 AVX-512 特性检测、唯一附魔应用、CLI 中断处理和 joint 缺省种子统一。试验性的 fixed_window 已移除，近似/MC 混分路径已由精确 MC 替换，本次不重复改动这些实现。
