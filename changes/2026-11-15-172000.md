# 调优默认最低加速 928

## 改动
- 配装调优的「加速 ≥」默认值由空改为 **928**（仍可手动清空/修改），
  对应 `constraints.stats = { jiasu: { min: 928 } }`，全量穷举与采样搜索都会过滤。

## 验证
- 实测（ws, 真实数据）：带 `jiasu >= 928` 的调优，基准配装加速 938 满足约束；
  `best.composed.stats.jiasu = 938`。

## 追加
- 「必须竞技场四件套」默认勾选（`arena4: true` → `required_sets = { "jingji-armor": 4 }`），
  与 928 最低加速一起作为调优默认约束；目录缺该套装时自动忽略。
