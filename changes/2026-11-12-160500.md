# 变宫 / 变徵 共享基础技能的秘籍

## 问题
`MijiDef::targets` 只按 `skill_id + sub_id` 精确匹配；《音·宫》秘籍绑定宫（14064/14474），
变宫（14298/18860）没有秘籍条目，秘籍面板里也不出现变宫——数据注释里的「复用秘籍」没有实现。

## 修复
- `MijiDef` / `MijiDefDTO` 新增 `applies_to: [[skill_id, sub_id], ...]`：
  - 非空时优先按共享列表匹配（基础技能 + 变体），为空时回退原 `skill_id/sub_id`；
  - 新增 `MijiDef::targets_skill(skill_id, sub_id)`，`targets` 复用它。
- `enrich_combat_dto` 的 `miji_ids` 配对改用 `targets_skill`：变宫的 `miji_ids` 现在包含宫的秘籍。
- 数据 `data/combat/mowen.toml`：
  - 《音·宫》系列 `applies_to = [[14064, 14474], [14298, 18860]]`；
  - 《音·徵》系列 `applies_to = [[14067, 14227], [14299, 18859]]`。

## 验证
- 新增单测 `miji_applies_to_shares_between_base_and_variant`；
- 新增集成测试 `variant_skills_share_base_miji`（真实 combat 数据：变宫/变徵 的 miji_ids 含基础技能秘籍）；
- `cargo test --workspace` / `cargo fmt --check` 全绿；前端 `tsc` + 157 项 vitest + build 通过。
