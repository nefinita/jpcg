# 调优请求导出 + 全量穷举自跑流程

## 改动
- 配装「调优设置」新增「**导出穷举请求**」按钮：导出与 app 调优同一口径的请求 JSON
  （指标固定 `total_damage`/确定性、约束沿用 928 加速 + 竞技场四件套等当前设置），
  可直接给 ws 上的 `gear-opt joint` 跑全量穷举。
- `jpcg_gear` 的 JSON API 新增 `export` 方法：把 loadout 转成 TOML 字符串，
  全量穷举得到的 `best.composed.loadout` 可转回 app 的「导入配装」格式。

## 用法
1. app → 配装 → 调优设置 → 导出穷举请求 → 得到 `jpcg-exhaustive-request-*.json`；
2. `scp` 到 ws，`cargo build --release -p jpcg_gear --bin gear-opt`；
3. `JPCG_DATA_DIR=$PWD/data ./target/release/gear-opt --catalog data/gear joint --request req.json > out.json`
   （64 核约 6~10 分钟，stderr 每 10 秒打印进度）；
4. `best.composed.loadout` 用 `api {"method":"export"}` 转 TOML，回 app 导入。
