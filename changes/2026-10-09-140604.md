## 行为修复（#2 附带）
原 **core 版** `skill_dto_to_skilltype` 用 `..Default::default()`，**丢失** `dot_interval/dot_duration/dot_up/wushijianshang/zhenshishanghai`。
而 `ComboStep::from`（保存连招预设时写技能快照）走的是 core 版 → **保存的预设快照丢 dot/无视减伤/真伤字段**。
统一到完整映射后修复；旧预设重存后内容会更完整（预期）。

## 单一来源（新增，`jpcg_core::host::conv`）
- DTO→core：`player_from_dto` / `hostile_from_dto` / `xinfa_from_dto` / `buff_from_dto` / `coefficient_from_dto` / `skill_pool_item_to_skilltype` / `into_core`
- core→DTO：`player_to_dto` / `hostile_to_dto` / `xinfa_to_dto` / `buff_to_dto` / `coefficient_to_dto` / `skilltype_to_pool_item`（转 pub）
