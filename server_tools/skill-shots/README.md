# skill-shots：截图 → 结构化技能数据

把游戏内人工截的**技能 tooltip / 秘籍选择页 / 奇穴选择页 / 属性面板**批量 OCR，
输出成结构化 JSON，用于校对 `data/shuxing` 与 `#92` 时序字段。

设计前提：现代客户端把伤害公式挪进了引擎，`scripts/skill/*.lua` 里只剩
「调用哪个伤害通道」，所以**面板数值只能靠截图**。截图的另一个好处是
基础伤害区间、释放时间、调息、秘籍加成都在 tooltip 里一次性可见。

## 目录约定

```
data/skill-shots/                     # 根目录，每个子目录 = 一个职业
  莫问/
    攻击力.png                         # 可选：属性面板（最终XX攻击），放在职业根目录
    技能/
      宫/
        宫.png                         # 技能 tooltip
        秘籍/
          秘籍页.png                   # 「秘籍选择」整页（一页 8 张卡）
      商/
        ...
    奇穴/
      第一重/洞天.png                   # 每个奇穴一张 tooltip 截图
      第二重/殊曲.png
      第三重/凝眉.png
      第四重/冻泉.png
      第五重/相依.png
      第六重/不愧君.png                 # 绝招类：额外按技能解析伤害/调息
      混选奇穴/秋霜.png
```

- 文件名随意，职业/技能/奇穴位置靠**目录名**确定。
- 技能目录下的图片：技能 tooltip；`秘籍/` 子目录下的图片：秘籍选择整页。
- 奇穴目录下的图片：单个奇穴的 tooltip。**直接截整个武学窗口也可以**——工具会把
  窗口按候选区域切块、逐块放大识别，取最像 tooltip 的一块（截图时鼠标停在奇穴上
  即可）。文件名 = 奇穴名，目录名 = 重数（`第一重`~`第六重`、`混选奇穴`），
  与 `#92` 的 `QixueDef.slot` 一一对应；文案里的「变徵」「商」「角」会被抽成
  `targets`，数字（伤害/秒数/层数）抽成 `numbers`，供后续人工映射到技能修正。
- 「绝招」类奇穴本身就是可施放技能，除说明文本外还会额外解析出
  `active`（伤害区间、攻击力贡献、调息、距离、属性），并在 `skills[]` 里输出一条
  **可直接进 #92 的技能条目**：

  ```json
  {
    "name": "不愧君",
    "jihuoqixue": "不愧君",
    "active": { "base_min": 850, "base_max": 875, "attack_bonus": 92291,
                "cooldown": 20.0, "range": 20, "element": "yin" },
    "ratio": 2100.01, "ratio_int": 2100, "ratio_residual": 0.0085
  }
  ```

  引擎侧 `jihuoqixue` 非空 = 该奇穴激活后才参与计算（未激活整条跳过），对应
  `data/combat/*.toml` 的 `[[skill_combat]]` 覆盖。
- **混选奇穴**：`混选奇穴/` 目录下的图片是 9 个候选。混选池一次选 3 个，游戏会
  **按混池顺序自动**排进 7~9 号槽位（不需要我们指定谁占哪个槽）。输出记成
  `pool: {size: 9, pick: 3, slot_from: 7, slot_to: 9}`，`slot_index` 为 `null`；
  `第一重`~`第六重` 则有 `slot_index: 1..6`。
- OCR 名词纠错（`--names`，默认读 `data/shuxing/*.toml` 的 `skill_name`）：
  只做两类——引号里的技能名按白名单编辑距离 1 纠正、以及实测高频错词表
  （变惩→变徵、曲凡→曲风……）。**不会**对正文做任意两字模糊替换，每次替换记录在
  输出的 `corrections` 里（`from`/`to`），便于人工复核。
- 整窗 OCR 会混进页签/水印，解析时从「被动招式 / 主动招式 / 绝招」标记处截取正文，
  多 psm 造成的重复句子也会按相似度去重；奇穴名优先取文件名。
- 换版本/技改时：**替换对应图片，重跑命令即可**，不用改代码。

## 用法

```sh
# 依赖：brew install tesseract tesseract-lang
cargo run -p skill-shots -- data/skill-shots

# 只跑一个职业；指定输出目录；调整整页切卡布局
cargo run -p skill-shots -- data/skill-shots --only 莫问 --out /tmp/shots-out
cargo run -p skill-shots -- data/skill-shots --page-cols 4 --page-rows 2 \
  --page-area 0.02,0.13,0.994,0.815
```

输出：

- `out/<职业>.json`：每个技能的 tooltip 字段、反推倍率、秘籍卡片、奇穴卡片；
- `out/summary.json`：总量与告警统计。

## 反推倍率

tooltip 的伤害是 `基础区间 + (攻击力贡献)`。拿属性面板里同属性的
「最终XX攻击」，`倍率 = 攻击力贡献 / 最终攻击 × 基准`。

当前版本内外功统一，基准默认 `160`（`--base` 可改）。倍率按游戏内口径存整数：`ratio_int = int(攻击加成 × 160 / 最终攻击力)`，结算时 `攻击加成 = ratio_int × 攻击力 / 160`。输出里的
`ratio_residual` 是取整残差，正常情况下应 < 0.02；偏大说明要么攻击力读错，
要么该技能不是线性倍率（多段、DOT、条件加成），需要人工看一眼。

## 已知限制

- OCR 会把字形相近的 `3%` 认成 `39%` 之类，`effect` 保留原文供核对；
  百分比明显不合理（>100）时建议人工复核。
- 「已装备」角标不在 v1 的解析范围内。
- 整页切卡布局是按无界当前 UI 调的，UI 改版时用 `--page-area` 重新标定。
