## 简单介绍

v2.2 的主题是 **「让计算器理解装备，让配装理解战斗」**：

- 🧮 新的**战斗时序引擎**开始接管加速、GCD、读条、CD、充能、形态切换；
- 🎛️ 计算页从「填属性」升级成**配装驱动的驾驶台**：12 个部位随手换，右侧伤害实时跟着变；
- 🧰 装备属性改由**逐职业规则**换算，不再是手抄最终面板；
- ⚡ **配装调优**从启发式抽样升级为**全量穷举 + GPU/CPU 双后端批量蒙特卡洛**，搜索空间内的最优解有保证；
- 🧠 连招草稿、驾驶台状态、结果基准全部**本地持久化**，切页面不丢；
- 🎨 一轮视觉走查后的空态、卡片、提示层级重做。

**旧130级配置文件不兼容新特性。旧计算器引擎将在新版本更新后保留切换入口，但只保证能保留到v2.3，后续将逐步删除。鉴于部分朋友可能不想使用新的配置文件，我们将单独开源v2.1版本的计算器并提供下载通道，但是不再为它提供更新和bug修复。**

## ✨ 这个版本在做什么

### 🧮 战斗时序引擎（#92 / #97）

伤害不再只是「点一下、出一串数字」，而是被放进一条真实的时间轴里：

| 能力 | 说明 |
|------|------|
| **加速** | 加速等级 ÷ 系数换算，读条 / GCD / DOT 总时长按 **16 帧/秒**量化（阶梯式下降，跨不过帧阈值就不变） |
| **加速上限** | 默认 25% 封顶；带「突破上限」标记的 buff / 奇穴按 `min(常规加速, 25%) + 突破部分` 叠加 |
| **GCD 与读条** | 每个技能可单独覆盖 GCD、GCD 通道；读条、引导、固定 GCD、不占 GCD 分别建模 |
| **CD 与充能** | 冷却、层数、充能恢复时间；CD 可选择性吃加速 |
| **形态切换** | 刀宗单持/双持、蓬莱上天等用数据驱动的 `form` 状态机表达，不写死门派分支 |
| **秘籍 / 奇穴** | 秘籍是挂在技能上的修正项；奇穴是「默认技能 → 独立条目」的替换映射 |
| **DOT** | 总跳数固定，总时长随加速缩短；属性在施加瞬间快照，伤害按目标实时减伤结算 |
| **事件输出** | 输出 `Cast / DotTick / FormSwitch / BuffGain` 事件流，前端可直接画时间轴 |

新配套数据放在 `data/combat/*.toml`

### 🎛️ 配装驱动驾驶台（#91 / #95 / #96 / #107）

- **12 个部位卡片平铺**：每个部位直接点「来源 · 基础/升级 · 属性套」，右侧合成属性与伤害实时刷新（125ms 防抖）。
- **手动属性降级为模式切换**：以后计算只在驾驶台完成，其他页面只做配置。
- **钉住基准 + 差值**：钉住当前配装与结果后再改，逐行显示 `+ / -` 与百分比；「一键恢复」回到钉住那一刻。
- **全局持久化**：配装、模式、计算结果、基准、连招草稿都落在本地，切页面、重启都不丢。
- **连招草稿按心法缓存**：切到别的门派再切回来，写到一半的连招还在。

### 🧰 逐职业属性换算（#100 / #98）

- 装备属性不再手抄最终面板：**裸装基础值 + 装备模板 → 逐职业 TOML 规则 → 玩家属性**，全链路可追溯。
- 转换面板会列出体质、五维、基础攻击、会心/破防转换与额外气血，并标注规则来源与是否已在游戏内验证。
- 旧版手填数值的配装已下线：打开旧存档会提示并一键切换到职业合成规则，避免静默少算。

### ⚡ 配装调优：全量穷举 × GPU/CPU 双后端（#94 → beta.2 重头戏）

之前介绍的「有界优化」这次真正跑满了全链路：

- **不再抽样，全量遍历**：调优只考虑升级档装备（有上限约束时保留基础档兜底），莫问 12 个槽位各 2 件升级候选，搜索空间 2^12 = **4096 套**一次跑完，结果标记 `complete = true`——搜索空间内的最优解有保证，不再是启发式近似的「应该差不多」。
- **新的计算后端 crate `jpcg_compute`**：CPU 端 **AVX-512 16 路**向量化（自动检测 f/dq/vl/bw 子集，缺失时回退），GPU 端经 **wgpu** 枚举本机所有适配器（Metal / Vulkan / DX12 皆可）。同一 seed 下 CPU 与 GPU 的击杀计数**逐候选完全一致**（macOS Metal 已对拍），想快用 GPU，想稳用 CPU。
- **击杀率目标 = 批量精确 MC**：新的 `kill_mc` 内核（f32 + 计数器哈希，标量 + AVX-512 双实现带 parity 测试）按 32k 候选/批批量跑 50k 路径蒙特卡洛，替换掉原来的正态近似；调优与计算器/排轴器**同一内核、同一口径**。
- **前端新增「平台」下拉与「停止」按钮**：自动 / CPU / 各 GPU 适配器任选，运行中可随时取消，进度实时可见。
- **默认约束即 PVP 实战口径**：竞技场四件套必须 + 最低加速 928。
- **击杀率统一固定种子（12345）**：手调属性后的排轴器击杀率与调优结果面板可直接比较，不再有 ±0.5% 的抽样误差干扰判断。
- **性能**：rayon 多线程并行、时间轴模板按线程复用（逐候选只换 player）、进攻输入缓存复用 MC、GPU 输入/输出/回读缓冲区复用——64 核服务器全量穷举约 **6~10 分钟**。
- **穷举请求导出**：调优设置里一键导出与 app 同口径的请求 JSON，可在工作站上用 `gear-opt` CLI 跑全量穷举，结果经 `loadout` 导出 TOML 回 app「导入配装」。

### 🎯 数值修正：11-12 技改与口径统一

- **莫问「洞天」伤害降低 5%**（2026-11-12 技改）：替换技能基础伤害 4851 → 4608，3 跳合计 14553 → 13824，带回归测试锁定。
- **变宫 / 变徵共享基础技能的秘籍**：修正项现在正确继承到变体技能上。
- **测量窗口改为「动作归属 + 显式边界」**：修复同刻前后技能互相吞噬、`start=0` 边界、显式开始/结束邻接零窗口三类问题；总伤 / DPS / 击杀曲线 / 伤害日志**同一口径**，窗口外 DOT 尾跳不再计入。
- **击杀概率曲线关联技能名**，并显示实际统计的测量窗口区间。

## 🚀 如何尝鲜

Github已提供编译好的版本。

想从源码构建，请先确认工具链版本：

| 依赖 | 版本要求 | 说明 |
|------|----------|------|
| **Rust** | **≥ 1.85.0** | workspace 使用 edition 2024，`rustup default stable` 即可，不需要 nightly |
| **Node.js** | `^22.22.2 \|\| ^24.15.0 \|\| >=26.0.0` | 前端构建与测试，CI 使用 Node 22 |
| 平台依赖 | — | Windows：WebView2 + MSVC 工具链；macOS：Xcode Command Line Tools；Linux：webkit2gtk 等 Tauri 依赖 |

```bash
rustc --version   # 需要 >= 1.85.0
node --version    # 需要 ^22.22.2 || ^24.15.0 || >=26.0.0

git clone https://github.com/nefinita/jpcg.git
cd jpcg
git switch dev
make all          # setup → frontend → updater → modules-dir → build-static
```

- 配装数据说明：[`data/gear/`](https://github.com/nefinita/jpcg/tree/dev/data/gear)
- 战斗时序数据说明：[`data/combat/README.md`](https://github.com/nefinita/jpcg/tree/dev/data/combat)
- 时序引擎验证：`cargo test -p jpcg_combo`，前端：`cd examples/jpcg_app && npm test`

> 首次构建会自动准备 updater sidecar 与前端产物；如果之前手动 `cargo build` 过 app，记得先 `make frontend updater`。
